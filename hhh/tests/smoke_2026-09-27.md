# Ten-event HHH reproduction check

The reference was EventProd's `events_000910581.lhe` (10,000 events). The new
sample was generated with seed 910582 and ten events using a clean extraction
of MG5_aMC 2.9.24, the bundled cards/model, and LHAPDF 6.3.0. Both samples
were showered with key4hep release 2025-05-29 and the patched k4SimDelphes
binary (`be648e4`). The existing EventProd MG5 directory was incomplete, so
the clean archive was used for the successful run.

The first ten LHE events of each sample passed the same checks: 42 TeV per
beam, PDF ID 260000, three Higgs bosons decaying to four b quarks and two tau
leptons, and `rwgt_1` through `rwgt_9` in the same coupling-point order.
The LHE headers report integrated weights of 0.0015611 pb (reference) and
0.0015421 pb (new), about 1.2% apart.

Both EDM4hep files contain ten events. Each has nine finite values in
`_EventHeader_weights`; the first frame identifies them as `rwgt_1` through
`rwgt_9` in `EventWeightNames` metadata. Each ROOT weight also matches its LHE
event weight. Different seeds do not imply equal event kinematics.
